# Contributing to OpenStick.tv

Thanks for helping. OpenStick is early (choosing a manufacturing partner), so the most useful contributions right now are feedback and ideas for the open layer: the home screen, integrations and casting.

- **Bugs and test results:** open an issue in the repo it concerns, using the templates.
- **Design changes:** open an issue to discuss before writing code.
- **Pull requests:** keep them small and focused. Sign off your commits (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).
- **Licences:** code is Apache-2.0, case and accessory designs CERN-OHL-S-2.0, docs and site content CC BY 4.0. By contributing you agree your work is released under the licence of the repo you contribute to.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
