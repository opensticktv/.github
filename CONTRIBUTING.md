# Contributing to OpenStick.tv

Thanks for helping. OpenStick is early (v0 prototype), so the most useful contributions right now are hardware test results and feedback on the [PRD](https://github.com/opensticktv/openstick/blob/main/docs/PRD.md).

- **Bugs and test results:** open an issue in the repo it concerns, using the templates.
- **Design changes:** propose them as a decision record in the [openstick](https://github.com/opensticktv/openstick/tree/main/decisions) repo before writing code.
- **Pull requests:** keep them small and focused. Sign off your commits (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).
- **Licences:** code is Apache-2.0, hardware files CERN-OHL-S-2.0, docs and site content CC BY 4.0. By contributing you agree your work is released under the licence of the repo you contribute to.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
