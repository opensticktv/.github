# OpenStick.tv

Open hardware you can buy: a 4K streaming stick with nothing selling to you.

OpenStick plays Netflix, HBO Max, Disney+ and Prime in 4K. The board and case designs are published, and everything we build on top is open source:

- a home screen with no ads and no sponsored rows
- open casting receivers alongside Google Cast
- control from Home Assistant and Apple Home, plus a local API
- mainboard schematics, layout and case CAD you can study, modify or build

Units ship locked, because services only send 4K to certified devices running locked software. You can unlock your own unit and run any OS; subscriptions then play at 720p. We say so up front.

**Status:** in development, choosing a chip and certification partner. Not for sale yet. Repositories open here as each part is ready.
